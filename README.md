# XZB Serveur

Base de site web pour presenter un serveur Rust.

## Fichiers

- `index.html` : structure du site et textes a modifier.
- `style.css` : design visuel du site.
- `script.js` : menu mobile et bouton de copie IP.
- `images/` : logos et visuels du site.

## A personnaliser

- Nom exact du serveur.
- IP et port dans le bouton `data-copy`.
- Lien Discord.
- Regles, planning wipe, staff et informations serveur.
